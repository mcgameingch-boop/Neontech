NEONTECH Website

วิธีเปิดใช้งาน:
1. แตกไฟล์ ZIP
2. เปิดไฟล์ index.html ด้วย Chrome, Edge, Firefox หรือ Safari
3. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Tailwind CSS และ Google Fonts จาก CDN

หมายเหตุ:
- เว็บไซต์นี้เป็นเดโมตามไฟล์ต้นฉบับ ไม่ใช่ระบบขายจริง
- ข้อมูลผู้ใช้/สินค้า/คำสั่งซื้อเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น
- ไม่มีฐานข้อมูลหรือระบบหลังบ้านส่วนกลาง
- QR และขั้นตอนชำระเงินเป็นข้อมูลจำลอง ห้ามโอนเงินจริง
- ก่อนเปิดขายจริง ต้องทำ backend, authentication, database และ payment gateway ที่ปลอดภัย
